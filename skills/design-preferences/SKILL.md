# Visual preferences

Apply these to every visual design or page you build or change.

- **Show which text matters more by font size and weight.** Add a small label above a heading only as a last resort,
  when you can say in one sentence why nothing else works. Never write that label in uppercase.
- **Separate sections with whitespace.** Add a thin dividing line only when you can say in one sentence what real
  reason it serves.

Name any exception and its one-sentence reason in your report.
